1. Аутентификация и авторизация
- Для доступа к новой системе SmartHome требуеся подтверждение входа, доступ предоставляется через отправку OTP на устройства собственников/администраторов
- Для разграничения прав администраторов используется RBAC (например, "право на подключение пользователя к сервисам" для роли Администратора, "право смотреть логи устройств" для Аудитора).

2. Требования к безопасности
- Для инициализации доступов пользвателей через домофон используются биометрические шаблоны, полученные путем преобразования фотографий собственников объектов недвижимости. В базе данных PropDevelopment хранятся только сами биометрические шаблоны, полученные из фотографий собственников. Во внешние сервисы также передаются только шаблоны.
- Преобразование фотографий в шаблоны реализуется через проприетарное приложение, развернутое в инфраструктуре PropDevelopment. Приложение поставляет партнер, реализующий сервис интеллектуального домофона.

3. Организация взаимодействия между системами предприятия и внешней платформой
- Во внешнюю систему компания PropDevelopment отправляет только биометрические данные собственников и номера автомобилей. Никакие персональные данные не выгружаются. 
- Приложение для преобразования фото в биометрические шаблоны развернуто в системе PropDevelopment
